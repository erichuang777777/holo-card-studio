# 乳癌守護戰

收集台大乳房醫學中心醫療團隊卡牌、整合多專科、陪伴病人對抗乳癌的單人卡牌遊戲原型。機制參照爐石戰記，美術與命名為原創。

## 執行

```bash
cd game
npm install                    # 安裝 three.js（3D 展示用）
python3 -m http.server 8765   # 或任何靜態伺服器
# 開啟 http://localhost:8765/
npm test                       # 規則引擎測試
node test/balance.mjs 10       # 平衡模擬：開 10 包時各關卡勝率
```

## 3D 角色展示（showcase.html）

照片浮雕：去背照片加上程式推算的深度圖，在 three.js 中位移成立體人物，站在全息展示台上。

- 拖曳旋轉（水平約 ±30 度）、滾輪或雙指縮放；視角按鈕：正面、特寫、側面。
- 換裝溶解（白袍、刷手服）、招牌技能演出、動漫式出場動畫（速度線、眼神特寫、剪影、名字砸下）。
- 照片浮雕只有正面資訊，轉超過約 30 度邊緣會拉長；要做 360 度旋轉需要真正的 3D 模型。

新增一位醫師：

```bash
pip install "rembg[cpu]" "opencv-python-headless<5" numpy pillow
python3 tools/prepare_portrait.py assets/doctors/<id> coat=<白袍照片> scrubs=<刷手服照片>
# 可選：assets/doctors/<id>/profile.json 填姓名、教職、專長、能力值、招牌技能、台詞
# 開啟 showcase.html?doctor=<id>
```

`assets/doctors/` 是個人肖像，已排除在版本庫之外。

## 規則

- 法力水晶每回合 +1（上限 10）；每回合抽 1 張；手牌上限 10（爆牌銷毀）；場上隨從上限 7；牌庫抽空後受疲勞傷害。
- 起手換牌；30 張牌組；傳說卡每副限 1 張，其他限 2 張。
- 關鍵字：戰吼、嘲諷、衝鋒、回合結束、發現。
- 場地卡：醫院空間，每回合可啟動一次，耐久用完移除。
- 英雄技能「多專科會診」（2 費）：病人恢復 2 生命並獲得 1 護甲。
- 多專科團隊：場上有 3 個以上不同科別時，友方隨從 +1 攻擊。
- 衛教時刻：特定卡牌觸發問答，答對 +1 法力並抽 1 張牌。

## 乳癌：期別與亞型

| 期別 | 說明 |
|---|---|
| 第 0 期 | 原位癌，新手關，不分亞型 |
| 第 I–III 期 | 生命與牌組逐級增強 |
| 第 IV 期 | 轉移，兩個階段 |

| 亞型 | 加成 | 對應的治療卡 |
|---|---|---|
| 荷爾蒙受體陽性 | 每回合回復 2 生命 | 荷爾蒙治療停止回復 |
| HER2 陽性 | 護盾 6，每回合重生 2 | 標靶治療、腫瘤內科移除護盾 |
| 三陰性 | 敵方隨從 +1 攻擊 | 全體傷害治療 +1 |

亞型在對戰中是隱藏的，需要病理、影像或病理實驗室「揭露」。

## 抽卡與稀有度

- 稀有度依教職：教授＝傳說、副教授＝史詩、助理教授＝稀有、其他＝普通。
- 每包 5 張，至少 1 張稀有以上；連續 10 包未出傳說則保底。全部免費，每場勝利得 1 包。
- 超出可用數量的重複卡自動分解成經驗，可用來合成缺少的卡。
